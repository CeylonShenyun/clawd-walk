clawd-walk

像素 clawd 叼着信，沿红蓝航空虚线走向小木屋的加载条。它会看日子和天气换衣服。一个 js 文件，零依赖。

试穿

衣柜（会自己按日子挑）

用法

<script src="clawd-walk.js"></script>
<script>
  ClawdWalk.overlay({
    birthday: '03-21',          // 生日：捧蛋糕
    name: '阿橘',               // 生日那句后面带上名字
    anniversary: '07-07',       // 纪念日：抱花 + 小心心
    monthly: 20,                // 每月 20 号叼一朵花
    trips: [{ from: '2026-10-01', to: '2026-10-07' }],   // 这几天拎行李箱
    weather: { lat: 31.23, lon: 121.47 }                  // 下雨撑伞、天冷围围巾
  });
</script>
